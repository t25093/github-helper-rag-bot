# הגדרות מאגר - שינוי שם, ענף ראשי, הגנה, ארכוב ומחיקה

קובץ זה מסביר את פעולות הניהול העיקריות על מאגר. כל ההגדרות נמצאות בלשונית **Settings** בדף המאגר, וזמינות רק לבעלי הרשאת ניהול.

## שינוי שם מאגר

1. **Settings** ← **General** ← בשדה **Repository name** הקלד את השם החדש ← **Rename**.

GitHub מפנה אוטומטית מהכתובת הישנה לחדשה, אבל מומלץ לעדכן את הכתובת בכל מחשב שבו הפרויקט משוכפל:
```
git remote set-url origin https://github.com/USER/NEW-NAME.git
```
**שים לב:** אם תיצור בעתיד מאגר חדש בשם הישן, ההפניה תפסיק לעבוד.

## שינוי הענף הראשי (Default branch)

הענף הראשי הוא הענף שמוצג כברירת מחדל ושאליו נפתחים Pull Requests.

לשינוי: **Settings** ← **General** ← אזור **Default branch** ← לחץ על סמל ההחלפה ובחר ענף.

שימוש נפוץ: מאגרים ישנים שהענף הראשי בהם נקרא `master`, ורוצים לעבור ל-`main`.

## הגנה על הענף הראשי

אפשר למנוע שינויים ישירים בענף הראשי, ולחייב שכל שינוי יעבור דרך Pull Request:
1. **Settings** ← **Branches** (או **Rules** ← **Rulesets** בממשק החדש).
2. הוסף כלל לענף `main`.
3. אפשרויות נפוצות:
   - **Require a pull request before merging:** אסור push ישיר, רק דרך PR.
   - **Require approvals:** ה-PR צריך אישור של אדם נוסף.
   - **Require status checks to pass:** הבדיקות האוטומטיות חייבות לעבור לפני מיזוג.
   - חסימה של force push ושל מחיקת הענף.

בעבודת צוות, ההגנה הזו מונעת את רוב התקלות שבהן מישהו "שובר" את הגרסה הראשית בטעות.

## הפעלה וכיבוי של תכונות

**Settings** ← **General** ← אזור **Features**: אפשר להפעיל או לכבות Issues, Projects, Discussions ו-Wiki. כדאי לכבות תכונות שלא משתמשים בהן, כדי שהמאגר יהיה נקי.

## ארכוב מאגר (Archive)

כשפרויקט הסתיים ולא מתכוונים לעדכן אותו עוד, אפשר לארכב אותו:
**Settings** ← **Danger Zone** ← **Archive this repository**.

מאגר מאורכב:
- נשאר גלוי (לפי ההרשאות הקיימות) וניתן להורדה
- הופך לקריאה בלבד: אי אפשר לבצע push, לפתוח Issues או Pull Requests
- מסומן בפס שמודיע שהוא מאורכב

אפשר לבטל את הארכוב בכל זמן מאותו מקום. ארכוב עדיף בדרך כלל על מחיקה.

## מחיקת מאגר

**Settings** ← **Danger Zone** ← **Delete this repository**. GitHub יבקש להקליד את שם המאגר לאישור.

**אזהרות:**
- המחיקה מוחקת את כל הקוד, ה-Issues, ה-Pull Requests וה-Releases.
- ה-Forks שאחרים יצרו מהמאגר לא נמחקים.
- לפני מחיקה, ודא שיש לך עותק אם תצטרך את הקוד בעתיד (שכפול מלא עם `git clone`).

## מחיקת ענפים ישנים בגיטהב

עם הזמן מצטברים ענפים שכבר מוזגו. לניקוי:
- **דרך האתר:** לשונית **Code** ← לחץ על רשימת הענפים (**branches**) ← סמל הפח ליד ענף.
- **דרך המחשב:**
  ```
  git push origin --delete branch-name
  ```

כדי ש-GitHub ימחק ענפים אוטומטית אחרי מיזוג: **Settings** ← **General** ← סמן **Automatically delete head branches**.
