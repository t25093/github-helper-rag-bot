# גרסאות, תגיות ו-Releases

קובץ זה מסביר איך מסמנים גרסאות של הפרויקט ומפרסמים אותן, כך שאחרים יוכלו להוריד גרסה יציבה.

## מה זה תגית (Tag) ומה זה Release

- **תגית (Tag):** סימון קבוע של commit מסוים בשם, למשל `v1.0.0`. בניגוד לענף, תגית לא זזה. היא תמיד מצביעה על אותה נקודה בהיסטוריה.
- **Release:** עמוד בגיטהב שנבנה על תגית, ומוסיף לה כותרת, תיאור של השינויים וקבצים להורדה. זו הדרך המקובלת "להוציא גרסה".

## מספור גרסאות (Semantic Versioning)

השיטה המקובלת היא שלושה מספרים: `MAJOR.MINOR.PATCH`, למשל `2.4.1`.
- **MAJOR:** שינוי גדול שעלול לשבור תאימות לגרסה הקודמת.
- **MINOR:** תכונה חדשה, בלי לשבור תאימות.
- **PATCH:** תיקון תקלות בלבד.

נהוג להוסיף את האות `v` לפני המספר בשם התגית: `v1.0.0`.

## יצירת תגית במחשב

יצירת תגית עם הודעה, על ה-commit הנוכחי:
```
git tag -a v1.0.0 -m "גרסה ראשונה"
```

תגיות לא עולות לגיטהב עם `git push` רגיל. צריך להעלות אותן במפורש:
```
git push origin v1.0.0
```
או את כל התגיות:
```
git push --tags
```

הצגת התגיות הקיימות:
```
git tag
```

## יצירת Release באתר

1. בדף המאגר, בצד ימין, לחץ **Releases** (או **Create a new release**).
2. לחץ **Draft a new release**.
3. בשדה התגית בחר תגית קיימת, או הקלד שם חדש ליצירת תגית.
4. כתוב כותרת ותיאור. הכפתור **Generate release notes** יוצר אוטומטית רשימה של ה-Pull Requests שנכנסו מאז הגרסה הקודמת.
5. אפשר לצרף קבצים, למשל קובץ הפעלה או חבילה מוכנה, בגרירה לאזור הקבצים.
6. אם זו גרסה ניסיונית, סמן **Set as a pre-release**.
7. לחץ **Publish release**.

## מה מקבלים מ-Release

- עמוד מסודר עם כל הגרסאות והשינויים בכל אחת.
- לכל Release, גיטהב מצרף אוטומטית את קוד המקור להורדה כקובץ ZIP ו-tar.gz.
- משתמשים שאין להם Git יכולים להוריד גרסה יציבה בלחיצה.

## חזרה לגרסה מתויגת

לצפייה בקוד כפי שהיה בגרסה מסוימת:
```
git switch --detach v1.0.0
```
במצב הזה אפשר לצפות ולהריץ, אבל לא כדאי לבצע commits. לחזרה לענף הראשי: `git switch main`.

לפתיחת ענף חדש מגרסה ישנה, למשל לתיקון תקלה בה:
```
git switch -c fix-v1 v1.0.0
```

## מחיקת תגית

מחיקה מהמחשב:
```
git tag -d v1.0.0
```
מחיקה מגיטהב:
```
git push origin --delete v1.0.0
```
**שים לב:** אם אחרים כבר הורידו את התגית, מחיקה ויצירה מחדש באותו שם עלולות לבלבל. עדיף ליצור גרסה חדשה עם מספר חדש.
