# מילון מונחים עברית-אנגלית ל-Git ו-GitHub

קובץ זה מתרגם מונחים נפוצים, כדי ששאלות בעברית יתאימו למונחים באנגלית שבתיעוד ובפקודות. כל סעיף מכיל מונח אחד: התרגום, הסבר קצר והפקודה הקשורה.

## גיט - Git
תוכנה לניהול גרסאות שמותקנת במחשב. היא שומרת את היסטוריית השינויים בקבצי הפרויקט, ומאפשרת לחזור לגרסה קודמת ולעבוד במקביל בענפים.
Git עובד במחשב שלך. כשאומרים "להעלות לגיט" מתכוונים בדרך כלל להעלאה לגיטהב, שנעשית בפקודה `git push`.
נקרא גם: גיט, מערכת ניהול גרסאות.

## גיטהב - GitHub
אתר שבו שומרים מאגרי Git באינטרנט. הוא מאפשר לגבות את הפרויקט, לשתף אותו ולעבוד עליו יחד עם אחרים (Pull Requests, Issues ועוד).
ההבדל: Git הוא התוכנה במחשב, ו-GitHub הוא השירות באינטרנט שמאחסן את המאגרים.
נקרא גם: גיטהב, גיטהאב.

## אתחול מאגר - Init
הפיכת תיקייה רגילה במחשב למאגר Git. מריצים פעם אחת, בתוך תיקיית הפרויקט.
פקודה: `git init`
נקרא גם: יצירת מאגר, התחלת מעקב.

## מצב - Status
הצגת מצב הקבצים: אילו קבצים השתנו, אילו מסומנים ל-commit, ואילו Git עוד לא עוקב אחריהם.
פקודה: `git status`
נקרא גם: בדיקת מצב, מה השתנה.

## הגדרות - Config
הגדרות של Git, למשל השם והאימייל שיופיעו על כל commit.
פקודות: `git config --global user.name "השם שלך"`, `git config --global user.email "המייל שלך"`, `git config --list`
נקרא גם: הגדרה ראשונה, קונפיג.

## מאגר - Repository (repo)
תיקיית פרויקט שמנוהלת ב-Git, כולל כל היסטוריית השינויים. מאגר מקומי נמצא במחשב, ומאגר מרוחק נמצא בגיטהב.
פקודות: `git init` (יצירה), `git clone` (שכפול).
נקרא גם: ריפו, פרויקט.

## שכפול - Clone
הורדת עותק מלא של מאגר מגיטהב למחשב, כולל ההיסטוריה והחיבור לגיטהב.
פקודה: `git clone URL`
נקרא גם: הורדת פרויקט.

## שמירת שינויים - Commit
"תמונת מצב" של הפרויקט בנקודת זמן, עם הודעה שמתארת את השינוי.
פקודה: `git commit -m "הודעה"`
נקרא גם: קומיט, שמירה.

## סימון להוספה - Stage / Add
סימון קבצים שייכללו ב-commit הבא. האזור שבו נמצאים הקבצים המסומנים נקרא staging area.
פקודה: `git add`

## דחיפה - Push
העלאת commits מהמחשב לגיטהב.
פקודה: `git push`
נקרא גם: העלאה, להעלות לגיטהב, עדכון בגיטהב.
להעלאת פרויקט שעדיין לא נמצא בגיטהב צריך קודם `git init`, `git add`, `git commit` ו-`git remote add`, ורק אז `git push`.

## משיכה - Pull
הורדת שינויים מגיטהב ושילובם בעותק שבמחשב.
פקודה: `git pull`
נקרא גם: עדכון מגיטהב, סנכרון.

## הבאה - Fetch
הורדת מידע על שינויים מגיטהב בלי לשלב אותם בקבצים. `pull` הוא בעצם `fetch` ואחריו `merge`.
פקודה: `git fetch`

## ענף - Branch
קו פיתוח נפרד במאגר. הענף הראשי נקרא בדרך כלל `main` (ובמאגרים ישנים `master`).
פקודות: `git branch`, `git switch -c`
נקרא גם: בראנץ'.

## מיזוג - Merge
שילוב השינויים מענף אחד בענף אחר.
פקודה: `git merge`

## התנגשות - Conflict
מצב שבו אותן שורות שונו בשני ענפים, ו-Git לא יודע איזו גרסה לבחור. צריך לפתור ידנית.
נקרא גם: קונפליקט, merge conflict.

## בקשת מיזוג - Pull Request (PR)
בקשה בגיטהב למזג ענף לענף אחר, עם אפשרות לבדיקה והערות לפני המיזוג.
נקרא גם: פול ריקווסט, PR. (בכלים אחרים, כמו GitLab, נקרא Merge Request.)

## פיצול - Fork
עותק של מאגר של מישהו אחר בתוך החשבון שלך בגיטהב.
נקרא גם: פורק, מזלג.

## מרוחק - Remote
כתובת של מאגר מרוחק שהמאגר המקומי מחובר אליו. ברירת המחדל נקראת `origin`.
פקודות: `git remote -v`, `git remote add`, `git remote set-url`

## מקור עליון - Upstream
במאגר שנוצר מ-Fork: המאגר המקורי שממנו נוצר העותק.

## תגית - Tag
סימון קבוע של commit מסוים, בדרך כלל לסימון גרסה, למשל `v1.0.0`.
פקודה: `git tag`

## גרסה מפורסמת - Release
עמוד בגיטהב שמפרסם גרסה של הפרויקט, על בסיס תגית, עם תיאור וקבצים להורדה.

## כרטיס משימה - Issue
דיווח על תקלה, בקשה לתכונה או משימה, בתוך מאגר בגיטהב.
נקרא גם: אישיו, באג, משימה.

## שותף - Collaborator
משתמש שקיבל הרשאה לשנות מאגר.

## הנחה בצד - Stash
שמירה זמנית של שינויים שעוד לא בוצע להם commit, כדי לפנות את תיקיית העבודה.
פקודות: `git stash`, `git stash pop`

## ביטול - Revert / Reset / Restore
- `git revert`: יוצר commit חדש שמבטל commit קודם. בטוח גם אחרי push.
- `git reset`: מחזיר את הענף ל-commit קודם. בטוח רק לפני push.
- `git restore`: מבטל שינויים בקבצים שעוד לא בוצע להם commit.

## היסטוריה - Log
רשימת ה-commits במאגר.
פקודה: `git log`, `git log --oneline`

## הבדלים - Diff
הצגת השינויים שורה אחר שורה.
פקודה: `git diff`

## קובץ התעלמות - .gitignore
קובץ שמגדיר אילו קבצים Git לא יעקוב אחריהם ולא יעלה.

## טוקן גישה - Personal Access Token (PAT)
סיסמה מיוחדת שיוצרים בהגדרות GitHub, ומשמשת במקום סיסמה רגילה בהתחברות דרך HTTPS.

## מפתח SSH - SSH Key
זוג מפתחות (פרטי וציבורי) להתחברות מאובטחת לגיטהב בלי להקליד סיסמה.

## פעולות אוטומטיות - GitHub Actions / Workflow
הרצה אוטומטית של בדיקות או פעולות אחרות כשקורה משהו במאגר.
נקרא גם: CI, אוטומציה.

## אתר מהמאגר - GitHub Pages
שירות שמפרסם אתר סטטי מקבצים במאגר.
