# שיתוף פרויקט ועבודה משותפת בגיטהב

קובץ זה מסביר את הדרכים לשתף פרויקט: הצגה בלבד, הוספת שותפים לעבודה, וקבלת תרומות מאנשים מבחוץ.

## בחירת דרך השיתוף

| מה רוצים | הדרך המתאימה |
|---|---|
| שאחרים יוכלו לראות את הפרויקט | מאגר ציבורי ושליחת קישור |
| לשתף קובץ או שורות מסוימות | קישור לקובץ או לשורות |
| שאדם מסוים יעבוד איתך על הפרויקט | הוספה כ-collaborator |
| שכל אחד יוכל להציע שינויים | Fork ו-Pull Request |
| להעביר את הפרויקט לבעלות של מישהו אחר | העברת בעלות (Transfer) |

## מאגר ציבורי או פרטי

- **ציבורי (Public):** כל אחד ברשת יכול לראות את הקוד ולהוריד אותו. רק מי שקיבל הרשאה יכול לשנות.
- **פרטי (Private):** רק אתה ומי שהזמנת יכולים לראות.

לשינוי: בדף המאגר ← **Settings** ← בתחתית הדף, באזור **Danger Zone** ← **Change visibility**.

**לפני שהופכים מאגר לציבורי:** ודא שאין בו, גם לא בהיסטוריה, סיסמאות, מפתחות API או מידע אישי. ראה בקובץ האבטחה.

## שיתוף קישור לפרויקט, לקובץ או לשורות

- **קישור לפרויקט:** הכתובת של דף המאגר, למשל `https://github.com/USER/REPO`.
- **קישור לקובץ:** נכנסים לקובץ באתר ומעתיקים את הכתובת.
- **קישור לשורות מסוימות:** בתצוגת הקובץ לוחצים על מספר השורה הראשונה, ואז עם Shift על השורה האחרונה. הכתובת מתעדכנת ומסמנת את הטווח.
- **קישור קבוע (permalink):** קישור רגיל לקובץ מצביע על הגרסה העדכנית, ועלול להשתנות. קישור קבוע מצביע על גרסה מסוימת שלא תשתנה. מקבלים אותו מתפריט שלוש הנקודות ליד הקובץ ← **Copy permalink**, או בלחיצה על המקש `y` בתצוגת הקובץ.

## הוספת שותף לעבודה (Collaborator)

במאגר בחשבון אישי:
1. בדף המאגר ← **Settings** ← **Collaborators** (בתפריט הצד).
2. לחץ **Add people**.
3. הקלד את שם המשתמש או האימייל של האדם בגיטהב.
4. האדם מקבל הזמנה באימייל ובאתר, וצריך לאשר אותה. ההזמנה בתוקף 7 ימים.

במאגר בחשבון אישי, לכל collaborator יש הרשאה לקרוא ולכתוב: הוא יכול לבצע push, ליצור ענפים ולמזג Pull Requests. רק בעל המאגר יכול לשנות הגדרות, למחוק את המאגר או להוסיף שותפים.

**הסרת שותף:** באותו מקום, לחץ על **Remove** ליד שמו.

## הרשאות בארגון (Organization)

במאגר ששייך לארגון (למשל של צוות או של מוסד לימודים), אפשר לתת רמות הרשאה שונות:
- **Read:** צפייה והורדה בלבד
- **Triage:** ניהול Issues ו-Pull Requests, בלי שינוי קוד
- **Write:** שינוי קוד (push)
- **Maintain:** ניהול המאגר, בלי הגדרות רגישות
- **Admin:** הרשאה מלאה

מומלץ לתת לכל אחד את ההרשאה המינימלית שהוא צריך.

## עבודה משותפת של כמה אנשים על אותו פרויקט

כללים שמונעים רוב הבעיות:
1. **להריץ `git pull` בתחילת כל עבודה**, כדי לקבל את השינויים של האחרים.
2. **לעבוד בענפים נפרדים** ולא ישירות על `main`. ראה בקובץ ענפים ו-Pull Requests.
3. **להעלות שינויים לעיתים קרובות**, ולא לצבור עבודה של ימים.
4. **לתאם מי עובד על מה**, למשל בעזרת Issues. ראה בקובץ Issues וניהול משימות.
5. **אף פעם לא להשתמש ב-`git push --force`** על ענף משותף, כי זה מוחק את העבודה של אחרים.

## קבלת תרומות מאנשים מבחוץ (Fork ו-Pull Request)

בפרויקט ציבורי, כל אחד יכול להציע שינויים גם בלי שהוספת אותו כשותף:
1. הוא לוחץ **Fork** ויוצר עותק של המאגר בחשבון שלו.
2. מבצע שינויים בעותק שלו.
3. פותח Pull Request מהעותק שלו למאגר שלך.
4. אתה בודק את השינויים ומחליט אם למזג.

כך אתה שומר על שליטה מלאה, ורק שינויים שאישרת נכנסים לפרויקט.

## עדכון Fork מהמאגר המקורי

מי שעשה Fork צריך מדי פעם לעדכן את העותק שלו בשינויים מהמקור.

**דרך האתר:** בדף העותק לחץ **Sync fork** ← **Update branch**.

**דרך המחשב:**
```
git remote add upstream https://github.com/ORIGINAL-OWNER/REPO.git
git fetch upstream
git switch main
git merge upstream/main
git push
```
את שורת `git remote add upstream` מריצים רק בפעם הראשונה.

## שיתוף עם מי שאין לו Git

אנשים בלי Git ובלי חשבון יכולים:
- לצפות בקוד ישירות באתר, אם המאגר ציבורי.
- להוריד את הפרויקט כקובץ ZIP: כפתור **Code** ← **Download ZIP**.
- להוריד גרסה מוכנה מעמוד ה-Releases, אם פרסמת. ראה בקובץ גרסאות ו-Releases.

## העברת בעלות על מאגר (Transfer)

כשרוצים להעביר מאגר לחשבון אחר או לארגון:
1. **Settings** ← **Danger Zone** ← **Transfer ownership**.
2. הקלד את שם הבעלים החדש ואת שם המאגר לאישור.
3. אם ההעברה היא לחשבון אישי, הבעלים החדש צריך לאשר.

GitHub מפנה אוטומטית את הכתובת הישנה לחדשה, אבל מומלץ שכל מי שעובד על הפרויקט יעדכן את הכתובת אצלו:
```
git remote set-url origin https://github.com/NEW-OWNER/REPO.git
```
