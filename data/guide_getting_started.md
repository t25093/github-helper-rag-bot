# התחלת עבודה עם Git וגיטהב

קובץ זה מסביר מה צריך להכין לפני שעובדים עם Git וגיטהב בפעם הראשונה: התקנה, הגדרה, חשבון והתחברות, וגם את סדר העבודה היומיומי.

## מה זה Git ומה זה גיטהב

- **Git** הוא תוכנה שמותקנת במחשב ומנהלת גרסאות של הקבצים בפרויקט: שומרת "תמונות מצב" (commits), מאפשרת לחזור לגרסה קודמת, ולעבוד במקביל בענפים. Git עובד גם בלי אינטרנט.
- **גיטהב (GitHub)** הוא אתר שמאחסן מאגרי Git באינטרנט. הוא משמש לגיבוי, לשיתוף ולעבודה משותפת, ומוסיף כלים כמו Pull Requests ו-Issues.

הקשר ביניהם: עובדים ושומרים במחשב עם Git, ומעלים לגיטהב עם `git push`. מורידים שינויים מגיטהב עם `git pull`.

## התקנת Git

- **Windows:** מורידים מ-git-scm.com ← **Download for Windows**, ומתקינים. אפשר להשאיר את כל ברירות המחדל. ההתקנה כוללת גם את Git Bash ואת Git Credential Manager, שמטפל בהתחברות לגיטהב.
- **Mac:** מריצים בטרמינל `git --version`. אם Git לא מותקן, המערכת תציע להתקין את כלי הפיתוח (Command Line Tools). אפשר גם להתקין עם Homebrew: `brew install git`.
- **Linux (Ubuntu/Debian):** `sudo apt install git`.

אחרי ההתקנה **סוגרים ופותחים מחדש** את הטרמינל, ובודקים:
```
git --version
```
אם מופיע מספר גרסה, למשל `git version 2.47.0`, Git מותקן.

## הגדרה ראשונה: שם ואימייל

כל commit נחתם בשם ובאימייל. מגדירים אותם פעם אחת בכל מחשב:
```
git config --global user.name "השם שלך"
git config --global user.email "המייל שלך"
```
מומלץ להשתמש באותו אימייל שרשום בחשבון גיטהב, כדי שה-commits יקושרו לחשבון.

כדי שהענף הראשי במאגרים חדשים ייקרא `main`:
```
git config --global init.defaultBranch main
```
לצפייה בכל ההגדרות:
```
git config --list
```

## פתיחת חשבון בגיטהב

1. נכנסים ל-github.com ← **Sign up**.
2. ממלאים אימייל, סיסמה ושם משתמש, ומאשרים את האימייל.
3. מומלץ להפעיל מיד אימות דו-שלבי (2FA) בהגדרות החשבון.

שם המשתמש יופיע בכתובת של כל מאגר: `https://github.com/USER/REPO`.

## התחברות לגיטהב מהמחשב

גיטהב לא מקבל את סיסמת החשבון הרגילה בשורת הפקודה. יש שלוש דרכים להתחבר:

1. **Git Credential Manager (הכי פשוט ב-Windows):** בפעם הראשונה שמריצים `git push`, נפתח חלון או דפדפן להתחברות לגיטהב. מאשרים, והחיבור נשמר במחשב.
2. **טוקן גישה (Personal Access Token):** בגיטהב: תמונת הפרופיל ← **Settings** ← **Developer settings** ← **Personal access tokens** ← יוצרים טוקן חדש ומעתיקים אותו. כשהטרמינל מבקש סיסמה, מדביקים את הטוקן במקום הסיסמה. שומרים את הטוקן כמו סיסמה ולא מעלים אותו לשום מאגר.
3. **מפתח SSH:** יוצרים מפתח במחשב:
```
ssh-keygen -t ed25519 -C "המייל שלך"
```
מעתיקים את תוכן הקובץ הציבורי (שמסתיים ב-`.pub`) לגיטהב: **Settings** ← **SSH and GPG keys** ← **New SSH key**. בודקים את החיבור:
```
ssh -T git@github.com
```
עם SSH משתמשים בכתובת מאגר מהצורה `git@github.com:USER/REPO.git`.

## הורדת פרויקט קיים מגיטהב למחשב

כדי לעבוד על מאגר שכבר נמצא בגיטהב:
```
git clone https://github.com/USER/REPO.git
cd REPO
```
`git clone` מוריד את כל הקבצים וההיסטוריה, ומחבר את התיקייה לגיטהב. אחרי זה אפשר לעבוד ולהעלות שינויים עם `git push`.

## סדר העבודה היומיומי

```
git pull
(עבודה על הקבצים)
git status
git add .
git commit -m "תיאור קצר של השינוי"
git push
```
1. `git pull`: מורידים את השינויים האחרונים מגיטהב.
2. עובדים על הקבצים.
3. `git status`: בודקים מה השתנה.
4. `git add .`: מסמנים את השינויים.
5. `git commit -m "..."`: שומרים תמונת מצב עם הודעה.
6. `git push`: מעלים לגיטהב.

## פקודות לבדיקת מצב

- `git status`: אילו קבצים השתנו ואילו מסומנים ל-commit.
- `git log --oneline`: רשימה קצרה של ה-commits.
- `git diff`: השינויים שעוד לא סומנו, שורה אחר שורה.
- `git remote -v`: לאיזה מאגר בגיטהב התיקייה מחוברת.
- `git branch`: באיזה ענף נמצאים כרגע.

## כלים גרפיים

מי שמעדיף לא לעבוד בשורת הפקודה יכול להשתמש בכלי גרפי שמבצע את אותן פעולות בלחיצות:
- **GitHub Desktop:** תוכנה חינמית של גיטהב ל-Windows ול-Mac.
- **VS Code:** לעורך הקוד יש לשונית **Source Control** מובנית, עם כפתורים ל-commit, ל-push ול-pull.
